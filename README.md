Digital-Recipe-Book


Digital-Recipe-Book is a web-based recipe management application that lets users create, organize, and manage their favorite recipes in one place. Users can add new recipes, browse existing ones, rate them, and delete recipes when needed. Users can sign up, log in and manage their personal recipe book from a private profile page.

Features
User signup and login with Passport
Create Recipes: Add new recipes using a user friendly form on the homepage.
Browse Recipes: View all saved recipes on the homepage, displaying recipe name and recipe details.
Update Recipes: Rate recipes based on personal preferences and experiences.
Delete Recipes: Easily remove recipes from the recipe collection.

Tech stack
Frontend: EJS, CSS, JavaScript, and Bootstrap
Backend: Node.js, Express
Database: MongoDB Atlas

What I learned
How to structure an Express.js application using the MVC architecture, separating database operations, application logic, and user interface components to create more organized and maintainable code. I also gained experience working with Passport.js to implement user authentication and manage secure login functionality.

## Installation

1. Clone repo
2. run `npm install`

## Usage

1. run `node server.js`
2. Navigate to `localhost:8080`
